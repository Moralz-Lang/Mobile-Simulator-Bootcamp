# Installing Test Apps

## Purpose
Before analyzing applications, you need controlled test apps to observe behavior safely.

---

## Safe Sources for Test Apps
- Google Play (trusted apps)
- Open-source APK samples
- Emulator-installed system apps

---

## Installation Environments

### 1. Android Emulator
- Safe isolated environment
- No real device risk

### 2. iOS Simulator
- Used for UI-level testing
- Limited system access

---

## Security Principle

Never test unknown APKs on real devices.

Always assume:
> "Untrusted app = potential risk"

---

## What to Observe After Installation (Provide Thorough Example to expand on with Walkthroughs with Organized structure and what to look at with examples )
- Permissions requested
- Network behavior
- UI structure
- Background activity
