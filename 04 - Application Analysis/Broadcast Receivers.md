# Broadcast Receivers

## What Are They?
Components that respond to system-wide events.

---

## Examples of Events
- Device boot completed
- Battery low
- Network change
- App installed

---

## How They Work
- Listen for system broadcasts
- Trigger predefined actions

---

## Security Perspective

Broadcast receivers can:
- Trigger background behavior without user action
- Respond to system changes automatically

---

## Risk Insight

Malicious apps may:
- Trigger actions on boot
- Run without user interaction
- Monitor system state

---

## Key Concept

> Broadcast Receivers = Event-driven execution triggers
