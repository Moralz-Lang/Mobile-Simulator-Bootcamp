# Services

## What is a Service?
A Service runs in the background without a user interface.

---

## Types of Services

### 1. Started Service
- Runs until stopped

### 2. Bound Service
- Connected to another component

---

## Examples
- Music playback
- File downloads
- Sync operations

---

## Security Perspective

Services can:
- Run silently
- Process data in background
- Persist longer than UI

---

## Risk Insight

Poorly designed services can lead to:
- Background data leakage
- Unnoticed execution
- Resource abuse

---

## Key Concept

> Services = invisible execution layer
