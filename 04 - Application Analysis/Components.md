# Android App Components

## Overview
Android apps are built from four main components.

---

## 1. Activities
- UI screens
- User interaction layer

Example:
- Login screen
- Settings screen

---

## 2. Services
- Run in background
- No UI

Examples:
- Music playback
- Background syncing

---

## 3. Broadcast Receivers
- Respond to system events

Examples:
- Battery low
- Boot completed
- Network changes

---

## 4. Content Providers
- Share data between apps

Examples:
- Contacts database
- Media storage access

---

## Security Insight

Each component is an **entry point into app behavior**

---

## Key Concept

> More components = more potential attack surface
