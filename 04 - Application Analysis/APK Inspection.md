# APK Inspection

## What is APK Inspection?
The process of analyzing an Android app package to understand its structure and behavior.

---

## What You Look For

### 1. Permissions
- What the app requests
- Whether they match functionality

### 2. Embedded Files
- Images
- Scripts
- Libraries

### 3. Code Structure
- Decompiled logic (conceptual understanding)
- App flow patterns

---

## Key Insight

APK inspection is like:
> “Opening a sealed box to understand how it works internally”

---

## Defensive Purpose
- Detect malicious intent
- Identify over-permissioned apps
- Understand data flow
