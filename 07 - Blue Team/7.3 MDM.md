# 1. What Is MDM?

## Definition

**Mobile Device Management (MDM)** is a security technology that allows organizations to remotely manage, monitor, and secure mobile devices.

Devices include:

```text
Smartphones
Tablets
Rugged Devices
Corporate-Owned Devices
Employee-Owned Devices
```

---

## Simple Explanation

Without MDM:

```text
Employee Phone

        ↓

No Visibility

        ↓

Unknown Apps

        ↓

Unknown Security Status

        ↓

Risk
```

---

With MDM:

```text
Mobile Device

        ↓

MDM Agent

        ↓

MDM Server

        ↓

Security Administrator
```

The organization gains visibility and control.

---

# 2. Why Organizations Need MDM

Modern companies allow:

- Remote work
    
- Mobile email access
    
- VPN access
    
- Cloud applications
    
- BYOD
    

This creates risks.

---

## Example Scenario

Employee phone:

```text
Email Access

      +

VPN

      +

Company Documents

      +

Authentication Apps
```

Phone stolen:

```text
Attacker obtains phone

        ↓

Access corporate resources

        ↓

Data breach
```

MDM reduces this risk.

# Components

## 1. Administrator Console

The security team uses this interface.

Allows:

- Device inventory
    
- Policy creation
    
- Reports
    
- Alerts
    
- Remote actions
    

---

## 2. MDM Server

The central management system.

Responsible for:

- Sending policies
    
- Receiving device status
    
- Managing applications
    
- Reporting compliance
    

---

## 3. Device Agent / Management Profile

Installed on devices.

Provides:

- Communication
    
- Policy enforcement
    
- Security checks
    

---

# 4. Device Enrollment

Enrollment connects a device to the MDM platform.

---

# Enrollment Process

Example:

```text
Employee receives phone

        ↓

Installs MDM profile

        ↓

Device authenticates

        ↓

MDM applies policies

        ↓

Device becomes managed
```

---

# 5. Types of Enrollment

---

# 5.1 Corporate-Owned Devices

Organization owns device.

Example:

```text
Company purchases 500 phones

        ↓

Preconfigured with MDM

        ↓

Employees receive managed devices
```

Advantages:

- Full control
    
- Strong security
    
- Easier compliance
    

---

# 5.2 BYOD

## Bring Your Own Device

Employee owns phone.

Example:

```text
Personal Phone

        +

Company Email

        +

Company Applications
```

Challenge:

Protect company data without controlling personal data.

---

Solution:

## Containerization

Example:

```text
Personal Area

-----------------

Work Container

-----------------

Company Data
```

The company controls:

- Work email
    
- Work apps
    
- Corporate files
    

Not:

- Personal photos
    
- Personal messages
    

---

# 5.3 Zero-Touch Enrollment

Large organizations automate deployment.

Example:

```text
Device shipped directly to employee

        ↓

Employee turns device on

        ↓

MDM automatically installs

        ↓

Policies applied
```

---

# 6. MDM Security Policies

MDM enforces security requirements.

---

# Password Policies

Examples:

Require:

```text
Minimum 8 characters

Complex passwords

Screen lock

Password expiration
```

---

# Encryption Enforcement

Require:

```text
Device encryption enabled
```

Purpose:

Protect data if device is stolen.

---

# Screen Lock

Policy:

```text
Lock after 5 minutes inactivity
```

---

# Operating System Requirements

Example:

```text
Android version >= 14

iOS version >= 18
```

Older systems may contain vulnerabilities.

---

# Root/Jailbreak Detection

Important control.

---

## Rooted Android

Means:

User has elevated privileges.

Risk:

```text
Malware gains deeper access

Security controls bypassed
```

---

## Jailbroken iPhone

Means:

Apple restrictions removed.

Risk:

```text
Unauthorized applications

Security protections disabled
```

---

MDM can detect:

```text
Root status

Jailbreak status

Security posture
```

---

# 7. Application Management

MDM controls applications.

---

# Application Inventory

MDM can see:

```text
Installed Applications

Application Versions

Installation Sources
```

Example:

Detected:

```text
com.fake.weather.app
```

Security team investigates.

---

# Application Whitelisting

Only approved applications allowed.

Example:

Allowed:

```text
Microsoft Outlook

Teams

VPN Client
```

Blocked:

```text
Unknown APKs
```

---

# Application Blacklisting

Block known risky applications.

Example:

```text
Cryptocurrency miners

Malicious apps

Unauthorized games
```

---

# Managed Application Deployment

Organization pushes apps.

Example:

```text
MDM Console

       ↓

Deploy VPN Application

       ↓

500 Devices Installed
```

---

# 8. Remote Actions

One of the most important MDM features.

---

# Remote Lock

Scenario:

Employee loses phone.

Administrator:

```text
Lock Device
```

Result:

User cannot access data.

---

# Remote Wipe

Scenario:

Phone stolen.

Administrator:

```text
Erase Device
```

Removes:

```text
Corporate Data

Accounts

Applications
```

---

# Selective Wipe

Important for BYOD.

Instead of deleting everything:

```text
Delete:

Corporate Email
Corporate Files
Corporate Apps

Keep:

Personal Photos
Personal Data
```

---

# 9. Compliance Monitoring

MDM continuously checks device security.

---

Example:

Policy:

```text
Require encryption

Require password

Require latest OS
```

Device status:

```text
Encryption ❌

Password ✔

OS ✔
```

Result:

```text
NON-COMPLIANT
```

---

# Conditional Access

MDM can integrate with identity systems.

Example:

```text
User attempts login

        ↓

Check device compliance

        ↓

Approved?

        ↓

Allow access
```

# 10. MDM and Incident Response

MDM is extremely valuable during investigations.

---

## Scenario

Employee reports:

"My phone is acting strange."

---

MDM Evidence:

Collect:

```text
Installed apps

Device status

OS version

Location history

Compliance state

Application inventory
```

---

## Investigation Example

Suspicious app:

```text
Weather Update Pro
```

MDM shows:

Installed:

Yesterday

Source:

Unknown

Permissions:

SMS  
Contacts  
Location

Status:

High Risk

---

Response:

```text
1. Disable access

2. Remove application

3. Collect logs

4. Reset credentials

5. Review account activity
```

---

# 11. MDM vs Antivirus

They solve different problems.

|MDM|Antivirus|
|---|---|
|Device management|Malware detection|
|Policies|Threat scanning|
|Compliance|File analysis|
|Remote wipe|Malware removal|
|Inventory|Signatures|

---

# 12. MDM vs EDR

|MDM|EDR|
|---|---|
|Controls devices|Detects threats|
|Applies policies|Investigates behavior|
|Manages apps|Detects attacks|
|Compliance|Incident response|

They often work together.

---

Why is BYOD challenging?

Answer:

---

## Question 3

What is selective wipe?

Answer:

Removing only corporate data while preserving personal information.

---

## Question 4

Why detect rooted devices?

Answer:

Because root access can weaken security controls and allow malware greater privileges.

---

What is conditional access?

Answer:

Allowing access only when a device meets security requirements.
