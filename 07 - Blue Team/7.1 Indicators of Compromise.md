# 7.1 Indicators of Compromise (IoCs)

---

## Learning Objectives

Understand what defenders look for after a compromise.

---

## What is an Indicator of Compromise?

An **Indicator of Compromise (IoC)** is evidence suggesting a device or application may have been compromised or is behaving unexpectedly. An IoC is not proof by itself, but it provides a starting point for investigation.

---

## Categories of IoCs

### 1. File-Based

Examples

- Unexpected APKs
- Unknown applications
- Modified application files
- Unknown certificates
- Unexpected configuration files

---

### 2. Network

Examples

- Connections to unfamiliar IP addresses
- Unusual DNS requests
- Frequent outbound HTTPS sessions
- Large uploads during idle periods

---

### 3. Process

Examples

- Unexpected background services
- Repeated process restarts
- Excessive CPU usage
- Unusual memory consumption

---

### 4. User Behavior

Examples

- Unexpected permission prompts
- Apps requesting permissions unrelated to their purpose
- Increased battery drain
- Unexplained data usage

---

### 5. System

Examples

- Developer Options enabled unexpectedly
- Unknown VPN configurations
- Unexpected accessibility services
- Unknown device administrator apps
---

Lists installed package names.

Useful for:

- Asset inventory
- Finding unknown applications
- Comparing devices

---

Useful for:

- Background applications
- Unexpected services
- Resource consumption

---

Examples:

- Activity Manager
- Package Manager

# Exercise 1 — Compare Two Android Devices / Emulator Snapshots

## Scenario

A security analyst receives two Android emulator snapshots.

### Device A — Baseline (Known Good)

This represents the expected corporate configuration.

### Device B — Investigated Device

This represents the device reported by a user.

The analyst must identify differences.

---

# Step 1 — Package Comparison

## Question

### Which packages differ?

---

## Purpose

Installed packages represent the software inventory of the device.

Unexpected applications are one of the first places defenders look.

A difference does **not automatically mean malware**.

The difference must be investigated.

---

## Device B

# Knowledge Check Answers

---

# Question 1

## What is an IoC?

Answer:

An Indicator of Compromise is evidence suggesting that a system, application, or device may have experienced suspicious or unauthorized activity.

Examples:

- Unknown application
    
- Suspicious network connection
    
- Unauthorized permission usage
    
- Unexpected process
    

---

# Question 2

## Does one IoC prove malware?

Answer:

No.

A single indicator only suggests further investigation is needed.

Example:

High battery usage alone does not prove malware because legitimate applications can consume significant resources.

Analysts use multiple indicators together.

---

# Question 3

## Which command lists installed packages?

Answer:

```bash
adb shell pm list packages
```

---

# Question 4

## Why is battery drain useful?

Answer:

Battery drain can reveal unusual background activity, excessive CPU usage, persistent services, or abnormal network communication.

However, battery usage alone cannot determine malicious activity.

It must be correlated with:

- Applications
    
- Permissions
    
- Network activity
    
- Logs
    
- Processes
    

---

# Daily Reflection

## What surprised you most about mobile IoCs?

Example Answer:

The most surprising aspect is that many indicators are not obvious malware signs. Something as simple as excessive permissions or unusual background activity can become important when combined with other evidence.

# Which indicators are strongest?

Strong indicators:

1. Unknown applications
    
2. Suspicious permissions
    
3. Unauthorized administrative privileges
    
4. Unknown network communication
    
5. Persistence mechanisms
    

---

# Which indicators produce the most false positives?

Common false positives:

- Battery usage
    
- High CPU
    
- Network traffic
    
- Background processes
    

Reason:

Many legitimate applications behave this way.

---

- Unknown applications

- Persistent background services
    

---

## Medium

- Battery drain
    
- Performance issues
