# Payload Concepts

## What is a Payload?
A payload is the **action that runs after a condition is met in a controlled test scenario**.

---

## Conceptual Flow

- Exploit → triggers condition
- Payload → defines outcome

---

## Types (Conceptual)

### 1. Command Shell Payload
- Provides command execution environment (lab simulation)

### 2. Meterpreter Payload
- Advanced interactive session model (conceptual framework)

### 3. Non-interactive Payloads
- Execute and exit behavior

---

## Key Insight

> Payload = "What happens after access is achieved"

Not the access itself.
