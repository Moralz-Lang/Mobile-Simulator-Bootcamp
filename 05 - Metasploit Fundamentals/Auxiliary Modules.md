# Auxiliary Modules

## What Are They?
Auxiliary modules perform **supporting tasks** such as scanning and enumeration.

---

## Common Functions

### 1. Port Scanning
- Identify open services

### 2. Service Enumeration
- Detect versions of running services

### 3. Protocol Testing
- Validate network behavior

---

## Example Use Case (Conceptual)

- Identify if a service is exposed
- Determine version information
- Map attack surface

---

## Key Insight

> Auxiliary modules do not exploit — they observe.
