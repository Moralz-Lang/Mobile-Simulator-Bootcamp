# Metasploit Modules

## What Are Modules?
Modules are independent pieces of functionality inside Metasploit.

---

## Types of Modules

### 1. Exploit Modules
- Attempt to trigger a vulnerability
- Used in controlled lab testing

---

### 2. Auxiliary Modules
- Scanning and enumeration
- No exploitation involved

Examples:
- Port scanning
- Service detection

---

### 3. Payload Modules
- Code executed after a successful condition (lab concept)
- Represents post-access behavior

---

### 4. Post Modules
- Used after a session is established
- Focus on system analysis

---

## Key Insight

> Each module is a single-purpose tool in a larger workflow.
