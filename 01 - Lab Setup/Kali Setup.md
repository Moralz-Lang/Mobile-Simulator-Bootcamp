# Kali Linux Setup (Security Lab Environment)

## Purpose
Kali Linux is used as a controlled security testing environment for learning defensive and offensive security concepts.

---

## Key Components
- Terminal (command execution)
- Network utilities
- Security frameworks (conceptual overview)
- Packet analysis tools

---

## Lab Guidelines
- Always use isolated environments
- Never test on real devices or networks
- Only use authorized virtual machines

---

## Core Idea
Kali is not “for hacking systems” — it is for:
- Understanding vulnerabilities
- Testing defensive posture
- Learning attack patterns in safe labs
