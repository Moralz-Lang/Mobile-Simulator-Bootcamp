# Android Studio (Development + Security Learning)

## Purpose
Android Studio is used to understand:
- App structure
- APK compilation process
- App lifecycle behavior

---

## Key Features
- Code editor
- Emulator integration
- Debugging tools
- Build system (Gradle)

---

## Security Relevance
Understanding Android Studio helps you learn:
- How apps are built
- Where permissions are defined
- How components interact

---

## Key Insight
If you understand how an app is built, you understand how it can be analyzed.
